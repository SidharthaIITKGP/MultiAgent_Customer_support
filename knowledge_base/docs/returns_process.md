# Returns Process

## What Can Be Returned?
- Physical products in original or near-original condition (reasonable inspection allowed)
- Defective items regardless of condition
- Wrong items shipped to you

## What Cannot Be Returned?
- Digital products (software licenses, downloadable content) — these are covered by the Refund Policy, not returns
- Consumable items once opened (e.g., consumable cartridges, filters)
- Personalized / custom-engraved items
- Items marked "Final Sale" at time of purchase

## Return Window
- **Standard returns**: 30 days from delivery date
- **Defective returns**: 90 days from delivery date

## How to Initiate a Return

### Step 1: Request a Return Authorization (RA)
Submit a support ticket:
- Subject: "Return Request — Order #[ID]"
- Include: reason for return, photos if damaged/defective
- We'll issue a Return Authorization number within 1 business day

### Step 2: Pack Your Item
- Use original packaging if available
- If original packaging is unavailable, use a sturdy box with adequate padding
- Include a slip of paper inside with your Order ID and RA number
- Do NOT write on the product packaging itself

### Step 3: Ship It Back
- **Defective items**: We provide a prepaid return label (emailed after RA approval)
- **Change-of-mind returns**: Customer pays return shipping
- Ship within 7 days of receiving the RA number
- Keep your tracking number until refund/replacement is confirmed

### Step 4: Inspection and Resolution
- We inspect returned items within 3 business days of receipt
- Resolution options:
  - **Replacement** (for defective/wrong items): Ships within 2 business days post-inspection
  - **Refund**: Processed within 3–7 business days to original payment method
  - **Rejection**: If item doesn't meet return criteria, we ship it back to you (no refund)

## Return Status
Track your return in the account portal: Orders → [Order ID] → Return Status

## Exchanges
We don't offer direct exchanges. To get a different item:
1. Return the original item (follow return process above)
2. Place a new order for the desired item
3. Your refund will process separately

## Damaged During Return Shipping
- Take photos of packaging before shipping
- If the carrier damages the item in transit, file a claim with the carrier using your tracking number
- Share the claim number with us — we'll work with you to find a resolution

## High-Value Returns ($200+)
- Signature required on return delivery
- Additional inspection documentation provided
- Refund may take up to 10 business days for high-value items
